# Swiggy Occasion Copilot

An AI agent that coordinates dining-out and food delivery in one conversation using Swiggy MCP servers.

Example:
"Plan date night for 2, Italian, budget ₹2000, dessert at home after."

The agent:
- Searches Dineout restaurants
- Checks live table availability
- Books reservations
- Prepares food delivery carts
- Handles staged confirmations
- Manages partial failures safely

## Tech Stack
- Next.js 14
- Claude API
- Swiggy MCP
- OAuth 2.1 PKCE
- Vercel
